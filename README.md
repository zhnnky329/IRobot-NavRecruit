# IRobot 导航方向 2027 招新大考核

本仓库用于西安电子科技大学 IRobot 战队算法组导航方向最终大考核。请 Fork 到自己的账号下，命名为 `IRobot-NavRecruit-自己名字`（如 `IRobot-NavRecruit-pgd`）。

## 考核内容

在真实机器人平台上独立完成一套完整的自主导航系统，包括实机数据采集、建图、地图整理、定位与自主到点导航，使机器人能够使用自己建立的地图稳定定位并完成导航。

定位与导航框架不限。可以使用 AMCL、Nav2 等成熟方案作为基础，也鼓励自主调研、选择和验证其他技术路线。本仓库不提供配套功能包，所需功能包、依赖和运行环境请自行选型与搭建。

- **基础考核：100 分。** 完成上述完整自主导航系统，并进行实机验证。
- **额外加分：最多 20 分。** 鼓励独立技术探索和进阶自主能力，例如动态障碍物检测与避障、自行设计行为树实现多目标导航或巡逻，以及其他能实际提升机器人自主能力的改进。请说明实现思路并展示实机效果。

## 提交要求

提交自己 Fork 后的仓库链接，仓库至少包含：

- 实际使用的代码、启动文件与配置；
- 自己生成的导航地图；
- README、实机导航视频及有意义的 Git Commit History。

README 请简要说明系统流程与技术选型、建图方法、定位与导航启动方式、主要 Topic 与 TF、关键配置修改、一次实际问题排查过程，以及 AI 使用情况和本人验证方式。有加分内容的，请一并说明。

请持续提交能体现开发过程的 Commit，不要在结束时一次性提交全部内容，也不要提交无法解释或未经实机验证的代码。

请勿提交 `build/`、`install/`、`log/`、IDE 配置、Python 缓存或无关文件。大型视频、rosbag 和 PCD 请通过其他方式提供，并在 README 中附上链接和说明。

## 推荐环境

Ubuntu 22.04、ROS 2 Humble 和 x86-64 计算机。
